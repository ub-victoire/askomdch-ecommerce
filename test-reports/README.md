# Test reports

This directory is reserved for evidence-based QA reporting:

- [Coverage reports](coverage-reports/)
- [Execution summaries](execution-summaries/)
- [Defect summaries](defect-summaries/)
- [Traceability reports](traceability/)
- [QA status reports](qa-status/)

The current Jira export contains no Xray execution results or evidence, and no coverage metrics are calculated here. Create reports only from verified execution records and retain links to their source evidence. Do not treat Jira issue status `To Do` as pass/fail data.
