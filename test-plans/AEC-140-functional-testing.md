## Objective

To validate the functional behavior of the AskOmDch e-commerce application through structured manual testing of the four functional Epics.

## Scope

The Test Plan covers the following functional areas:

- Account Management
- Checkout
- Product Browsing
- Cart Management

Testing will validate the documented user stories and acceptance criteria, including positive, negative and combined scenarios.

## Test approach

Testing will be performed manually through the AskOmDch web application using test cases managed in Jira/Xray.

Test cases will be organized into Epic-based Test Sets. Execution results, actual outcomes, evidence and defects will be recorded in Xray.

## Test organization

Four Epic-based Test Executions will be prepared:

- Account Management Test Execution
- Checkout Test Execution
- Product Browsing Test Execution
- Cart Management Test Execution

Smoke and Regression Test Sets will support the relevant testing activities.

## Test environment

- **Application:** [https://askomdch.com/](https://askomdch.com/)
- **Test execution environment:** Web browser.

## Entry criteria

- Relevant user stories and acceptance criteria are available.
- Test cases have been created and linked to their corresponding stories.
- Test Sets have been organized.
- The application is accessible.
- Required test accounts and test data are available.

## Exit criteria

- Planned test cases have execution results.
- Failed tests have been investigated.
- Confirmed defects have been logged in Jira/Xray.
- Execution evidence has been attached where applicable.
- Test coverage and overall quality status have been reported.

## Deliverables

- Functional Test Plan
- Epic-based Test Executions
- Test Run results and evidence
- Defect records
- Requirement Traceability Matrix
- Test Execution and Final QA Reports
